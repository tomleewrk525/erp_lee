# erp-system/public/AGENT.md

## 모듈 개요

이 디렉토리는 Next.js 애플리케이션의 정적 자산을 제공하는 데 사용됩니다. 이 폴더에 있는 파일들은 애플리케이션의 루트 경로에서 직접 접근할 수 있으며, 빌드 과정에서 최적화되거나 처리되지 않고 그대로 제공됩니다.

## 주요 목적

- **정적 파일 제공**: 이미지, 폰트, 웹 애플리케이션 매니페스트, 로봇 파일(robots.txt) 등 웹 서버를 통해 직접 제공되어야 하는 파일들을 배치합니다.
- **성능 최적화**: 웹 서버가 이 파일들을 빠르게 제공할 수 있도록 하여 애플리케이션의 초기 로딩 성능에 기여합니다.
- **SEO 및 웹 표준**: `favicon.ico`, `robots.txt`, `sitemap.xml` 등 검색 엔진 최적화(SEO) 및 웹 표준을 위한 파일들을 관리합니다.

## 포함된 주요 파일

- `file.svg`: 파일 아이콘으로 사용될 수 있는 SVG 이미지.
- `globe.svg`: 지구본 아이콘으로 사용될 수 있는 SVG 이미지.
- `next.svg`: Next.js 로고 SVG 이미지.
- `vercel.svg`: Vercel 로고 SVG 이미지 (Next.js 배포 환경 관련).
- `window.svg`: 창 아이콘으로 사용될 수 있는 SVG 이미지.

## 파일 추가 및 수정 시 고려사항

- **직접 접근**: `public` 폴더 내의 파일은 `/`를 기준으로 직접 접근 가능합니다. (예: `public/next.svg`는 `/next.svg`로 접근)
- **빌드 프로세스**: 이 폴더의 파일은 Next.js 빌드 프로세스에 의해 직접 복사되며, 별도의 번들링이나 최적화 과정을 거치지 않습니다.
- **보안**: 민감한 정보나 소스 코드는 `public` 폴더에 배치하지 않도록 주의합니다.
- **캐싱 전략**: 정적 자산에 대한 적절한 캐싱 전략을 설정하여 성능을 더욱 최적화할 수 있습니다.
