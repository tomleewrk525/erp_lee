# erp-system/app/AGENT.md

## 모듈 개요

이 디렉토리는 Next.js 애플리케이션의 핵심 라우팅 및 페이지 구조를 정의합니다. 각 하위 디렉토리는 ERP 시스템의 특정 업무 모듈(예: 회계, 인사, 재고, 구매, 영업)에 해당하며, 해당 모듈의 페이지와 관련된 로직 및 컴포넌트를 포함합니다.

## 주요 목적

- **모듈화**: ERP 시스템의 복잡한 기능을 업무 영역별로 분리하여 관리 및 개발 효율성을 높입니다.
- **라우팅**: Next.js의 파일 기반 라우팅 시스템을 활용하여 각 URL 경로에 맞는 페이지를 제공합니다.
- **코드 구성**: 각 모듈은 독립적인 `page.tsx`, `layout.tsx` (필요한 경우), `loading.tsx`, `error.tsx` 등을 가질 수 있으며, 이는 해당 모듈의 컨텍스트를 명확히 합니다.

## 포함된 주요 하위 디렉토리 (업무 모듈)

- `accounting/`: 회계 및 경리 관련 기능
- `auth/`: 사용자 인증 및 권한 관리
- `dashboard/`: 시스템 대시보드 및 개요
- `groupware/`: 그룹웨어 기능 (협업, 전자결재 등)
- `hr/`: 인사 및 급여 관리
- `inventory-dist/`: 재고 및 유통 관리
- `products/`: 품목 기준 정보 관리
- `purchase-mgmt/`: 구매 관리
- `purchases/`: 구매 발주 관련 트랜잭션
- `sales-mgmt/`: 영업 관리

## 모듈 추가 및 수정 시 고려사항

- **명확한 책임**: 각 모듈 디렉토리는 해당 업무 영역의 기능에만 집중하도록 설계합니다.
- **라우팅 규칙**: Next.js의 라우팅 규칙을 준수하며, 동적 라우팅이 필요한 경우 `[slug]` 또는 `[id]`와 같은 패턴을 사용합니다.
- **공통 컴포넌트 활용**: UI 일관성을 위해 `erp-system/components/ui`에 정의된 공통 컴포넌트들을 적극적으로 활용합니다.
- **데이터 관리**: 각 모듈의 페이지는 필요한 데이터를 효율적으로 가져오고 관리하는 방식을 정의합니다.
- **문서화**: 각 모듈 디렉토리에 `AGENT.md` 파일을 추가하여 모듈의 목적, 주요 기능, 사용법 등을 명확히 문서화합니다.
