# erp-system/hooks/AGENT.md

## 모듈 개요

이 디렉토리에는 애플리케이션 전반에서 재사용 가능한 커스텀 React Hooks가 포함되어 있습니다. 이러한 훅들은 복잡한 로직을 캡슐화하고 컴포넌트의 재사용성 및 가독성을 향상시키는 데 기여합니다.

## 주요 목적

- **로직 재사용**: 상태 관리, 이벤트 처리, DOM 조작 등 공통 로직을 여러 컴포넌트에서 쉽게 재사용할 수 있도록 합니다.
- **코드 간소화**: 컴포넌트 내부의 복잡한 로직을 훅으로 분리하여 컴포넌트 코드를 더 깔끔하고 읽기 쉽게 만듭니다.
- **유지보수성**: 기능별로 훅을 분리하여 코드 변경 시 영향을 최소화하고 유지보수를 용이하게 합니다.

## 포함된 주요 훅

### `use-mobile.ts`

- **설명**: 현재 뷰포트 너비를 기준으로 사용자가 모바일 환경에 있는지 여부를 감지하는 커스텀 훅입니다. 반응형 UI를 구현하거나 모바일/데스크톱 환경에 따라 다른 동작을 제공할 때 유용합니다.
- **기능**:
    - `window.matchMedia`를 사용하여 CSS 미디어 쿼리와 유사하게 뷰포트 너비를 감지합니다.
    - `MOBILE_BREAKPOINT` (768px)를 기준으로 모바일 여부를 판단합니다.
    - 컴포넌트 마운트 시 초기값을 설정하고, 뷰포트 크기 변경 시 상태를 업데이트합니다.
- **사용법**:
    ```tsx
    import { useIsMobile } from "@/hooks/use-mobile";

    function MyComponent() {
      const isMobile = useIsMobile();

      if (isMobile) {
        return <p>모바일 환경입니다.</p>;
      }
      return <p>데스크톱 환경입니다.</p>;
    }
    ```
