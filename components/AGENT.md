# erp-system/components/AGENT.md

## 모듈 개요

이 디렉토리에는 ERP 시스템 전반에서 재사용되는 React 컴포넌트들이 포함되어 있습니다. 주로 `shadcn/ui` 라이브러리를 기반으로 확장되거나, 애플리케이션의 특정 요구사항에 맞춰 커스텀된 UI 컴포넌트들로 구성됩니다.

## 주요 목적

- **재사용성**: UI 요소의 일관성을 유지하고 개발 시간을 단축하기 위해 공통적으로 사용되는 컴포넌트들을 정의합니다.
- **유지보수성**: 잘 정의된 인터페이스를 통해 컴포넌트 간의 의존성을 줄이고 개별 컴포넌트의 유지보수를 용이하게 합니다.
- **확장성**: `shadcn/ui`와 같은 디자인 시스템을 기반으로 하여 필요에 따라 새로운 컴포넌트를 추가하거나 기존 컴포넌트를 확장하기 용이합니다.

## 포함된 하위 디렉토리 및 주요 파일

- `ui/`: `shadcn/ui`의 래퍼 컴포넌트들 및 커스텀 UI 컴포넌트들이 위치합니다.
- `app-sidebar.tsx`: 애플리케이션의 메인 사이드바 내비게이션 컴포넌트.
- `site-header.tsx`: 애플리케이션의 전역 헤더 컴포넌트.
- `nav-main.tsx`, `nav-documents.tsx`, `nav-secondary.tsx`, `nav-user.tsx`: 사이드바 내비게이션을 구성하는 컴포넌트들.
- `theme-toggle.tsx`, `language-selector.tsx`: 전역 UI 설정 관련 컴포넌트.

## 컴포넌트 추가 및 수정 시 고려사항

- **일관성**: 기존 `shadcn/ui`의 디자인 원칙과 스타일을 최대한 따릅니다.
- **접근성**: 모든 컴포넌트는 웹 접근성 표준(ARIA)을 준수하도록 개발합니다.
- **테스트**: 새 컴포넌트를 추가하거나 수정할 때는 관련 테스트 케이스를 반드시 추가합니다.
- **문서화**: 각 컴포넌트의 목적, 사용법, Props 등을 `AGENT.md` 파일에 명확하게 문서화합니다.
