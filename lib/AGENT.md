# erp-system/lib/AGENT.md

## 모듈 개요

이 디렉토리에는 애플리케이션 전반에서 사용되는 유틸리티 함수, 헬퍼(helper) 함수 및 목업(mockup) 데이터가 포함되어 있습니다. 특정 기능 모듈에 종속되지 않고 여러 곳에서 공통적으로 활용될 수 있는 코드들을 모아 관리합니다.

## 주요 목적

- **공통 유틸리티**: 날짜 처리, 문자열 조작, 데이터 형식 변환 등 범용적으로 사용되는 함수들을 정의하여 코드 중복을 방지하고 생산성을 높입니다.
- **목업 데이터**: 개발 및 테스트 단계에서 백엔드 데이터 없이 프론트엔엔드 기능을 개발할 수 있도록 임시 데이터를 제공합니다. 실제 데이터 구조를 모방하여 프론트엔드 개발자가 쉽게 활용할 수 있도록 합니다.
- **코드 중앙화**: 재사용 가능한 코드들을 한곳에 모아 관리함으로써 프로젝트의 일관성을 유지하고 유지보수를 용이하게 합니다.

## 포함된 주요 파일

- `mock-activity-data.ts`: 활동 내역과 관련된 목업 데이터를 제공합니다.
- `mock-attendance-data.ts`: 근태 기록과 관련된 목업 데이터를 제공합니다.
- `mock-employee-data.ts`: 직원 정보와 관련된 목업 데이터를 제공합니다.
- `mock-payroll-data.ts`: 급여 내역과 관련된 목업 데이터를 제공합니다.
- `mock-product-data.ts`: 제품 정보와 관련된 목업 데이터를 제공합니다.
- `utils.ts`: 범용적으로 사용될 수 있는 다양한 헬퍼 함수들을 포함합니다 (예: 날짜 포매팅, 유효성 검사 등).

## 파일 추가 및 수정 시 고려사항

- **범용성**: 특정 모듈에만 사용되는 로직보다는 여러 곳에서 재사용될 수 있는 코드 위주로 추가합니다.
- **순수 함수**: 가능한 한 부수 효과(side effect)를 최소화하고 순수 함수 형태로 작성하여 테스트 용이성을 높입니다.
- **타입 정의**: TypeScript를 사용하여 함수의 입출력 및 데이터 구조를 명확하게 정의합니다.
- **문서화**: 각 유틸리티 함수나 목업 데이터의 목적, 구조, 사용법 등을 주석 또는 `AGENT.md` 파일에 명확히 문서화합니다.
